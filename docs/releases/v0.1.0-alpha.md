## Italiano

Prima pre-release privata di Stealth Link per Turtle Beach Stealth Ultra e Android 7.0 o successivo. Include notifiche Social con filtri per app e conversazione, simulatore, laboratorio del display, diagnostica locale e canale delle impostazioni in sola lettura.

Scarica l’APK allegato e consulta la guida prima delle prove App Link sul controller. Il comportamento effettivo del display, le sottoscrizioni cifrate, la riconnessione e la consegna a telefono bloccato richiedono una verifica sul dispositivo. `SHA256SUMS.txt` permette di verificare l’APK e la guida scaricati.

Se hai già installato una build debug, esporta prima i profili locali. Android richiede la rimozione della build debug prima di installare l’APK firmato con il certificato dedicato. I futuri aggiornamenti firmati con lo stesso certificato conservano la compatibilità con questa installazione.

## English

First private Stealth Link Android 7.0+ prerelease for Turtle Beach Stealth Ultra. It includes Social notification rules, a simulator, a display lab, local diagnostics and read-only controller settings.

Download the signed APK asset and use the attached guide for App Link tests. Encrypted subscriptions, reconnects, locked-phone delivery and physical display behavior require device testing. `SHA256SUMS.txt` covers the APK and the test guide.

If you have a debug build installed, export local profiles first. Android requires removing a copy signed with the debug certificate before installing this APK. Future versions signed with the same release certificate can update this installation.
